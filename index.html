صانعو المحتوى

دورات صناعة المحتوى على مواقع التواصل الاجتماعي

أسرار بناء وإدارة قنوات اليوتيوب وصفحات تيك توك وفيسبوك، خوارزميات الانتشار، كتابة السكربتات، هندسة الصوت والفيديو، وتحقيق الدخل وبناء جمهور وفي.

هاردوير وصيانة ميدانية

دورة صيانة الحاسب الآلي وتجميع العتاد وتثبيت الأنظمة

تشخيص وإصلاح الأعطال المادية (Hardware) والبرمجية (Software)، تجميع قطع الحواسيب، تهيئة البيوس (BIOS/UEFI)، وتثبيت وتأمين أنظمة Windows وLinux.

موظفون وإداريون ومحاسبون

دورة Excel Avancée للمحاسبين والإداريين

احتراف الدوال المركبة والمعقدة (XLOOKUP, INDEX/MATCH, SUMIFS)، الجداول المحورية (Pivot Tables)، تحليل البيانات المالية، وتصميم لوحات القيادة (Dashboards) التفاعلية.

الأساسيات الوظيفية

دورة البرامج المكتبية الأساسية الشاملة (Office)

إتقان العمل المكتبي الاحترافي بحزمة مايكروسوفت أوفيس: معالجة النصوص وتنسيق المراسلات (Word)، الجداول الإحصائية (Excel)، والعروض التفاعلية (PowerPoint).

طلبة الجامعات والتكوين المهني

دورة تصميم وتنسيق مذكرات التخرج الأكاديمية

دورة موجهة لطلبة الليسانس والماستر والتقني سامي: تنسيق المذكرات، إعداد الهوامش والفهارس التلقائية، ترقيم الفصول، إدراج الجداول والأشكال، وضبط المراجع بالمعايير الرسمية.

تسيير البيانات

دورة تسيير قواعد البيانات وتطبيقات Microsoft Access

تحليل وبناء قواعد البيانات، العلاقات والمفاتيح، صياغة الاستعلامات (Queries)، تصميم النماذج وواجهات المستخدم وإعداد التقارير الإدارية الجاهزة للطباعة.

صناعة الميديا الرقمية

دورة مونتاج الفيديو الرقمي وصناعة الفيديوهات

المونتاج الشامل باستخدام Adobe Premiere وCamtasia وFilmora: تقطيع وتزامن الصوت، تصحيح الألوان، المؤثرات الانتقالية، والعناوين الديناميكية والتصدير الاحترافي.

الديزاين والهوية البصرية

دورة التصميم الغرافيكي والديزاين (Photoshop & Canva)

تصميم المنشورات الرقمية، البنرات الإعلانية، الصور المصغرة لليوتيوب (Thumbnails)، وإتقان أدوات الفوتوشوب وكانفا في تصميم المواد التسويقية المتناسقة.

الإدارات والمكاتب

دورة السكرتاريا المكتبية والتحرير الإداري الرقمي

أصول التحرير الإداري للمراسلات والتقارير والمحاضر الرسمية، تقنيات الأرشفة والتوثيق الرقمي، وسرعة معالجة الملفات وحسن تنظيم المكاتب الإدارية.

هندسة البيانات الاحترافية

دورة هندسة قواعد البيانات المتقدمة (SQL Server & MySQL)

نمذجة قواعد البيانات (ERD)، كتابة استعلامات SQL المتقدمة، الإجراءات المخزنة (Stored Procedures)، الفهارس، النسخ الاحتياطي، وحماية البيانات المؤسساتية.

الشبكات والبنية التحتية

دورة تركيب وضبط شبكات الحواسيب (LAN / WLAN)

إعداد الموجهات والموزعات (Routers & Switches)، كبس كابلات الشبكة، توزيع عناوين IP، مشاركة المجلدات والطابعات، وتأمين الشبكات السلكية واللاسلكية.

برمجة الموبايل

دورة برمجة تطبيقات الأندرويد بالذكاء الاصطناعي

بناء تطبيقات أندرويد حقيقية وقابلة للنشر على الهواتف الذكية بالاستعانة بمحركات الذكاء الاصطناعي وأدوات البرمجة السريعة بدون تعقيدات الأكواد الطويلة.

الاستضافة والسيرفرات

دورة إدارة واستضافة المواقع (cPanel, DNS, Cloudflare)

شراء وربط أسماء النطاقات (Domains)، إعداد Cloudflare لحماية وتسريع المواقع، إدارة لوحات cPanel، قواعد البيانات، والبريد المهني وشهادات الأمان SSL.

برنامج مخصص

دورة تدريبية حسب الطلب (برامج مخصصة للأفراد والمؤسسات)

برنامج تدريبي مكثف ومفصل ومصمم خصيصاً لتلبية متطلباتك أو متطلبات فريق عمل مؤسستك، سواء للتحضير لمسابقة، ترقية وظيفية، أو إنجاز مشروع تقني محدد.
